# Python File Organizer

A Python program that automatically sorts files into folders based on their file type and extension.

## What it does

- Sorts files into categories like Images, Documents, Audio, and Videos
- Creates folders for different file extensions
- Moves files into their appropriate folders
- Puts unrecognized file types into an Other folder

## What I learned

- Python file and folder handling
- The os module
- File extensions and paths
- Dictionaries and lists
- Functions, loops, and conditionals
- Creating and moving files and folders
